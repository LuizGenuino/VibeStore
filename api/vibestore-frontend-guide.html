1. Escopo, fontes e premissas

Este guia é o contrato de implementação do frontend da VibeStore reiniciada (Vue 3 + TypeScript + Vuetify 3 + Pinia + Vue Router 4) sobre o backend dos módulos 001 a 007. Ele foi escrito para que o desenvolvedor implemente todas as telas, rotas, services, stores e ações sem precisar abrir o Supabase. Nenhuma linha de frontend real foi criada; rotas, nomes de arquivo, nomes de store e de service são propostas deste guia.

2.3 Regras transversais (valem para todas as telas)

RegraDetalhe
Escrita só por RPCCatálogo, estoque, pedidos, despesas, loja (criar/publicar/arquivar) escrevem somente por RPC. Tabelas não têm GRANT INSERT/UPDATE/DELETE para authenticated, exceto: stores (UPDATE de 13 colunas), profiles (UPDATE full_name/phone/avatar_path), plans (UPDATE name/description/is_active, só SUDO) e roles/permissions/role_permissions (CRUD, só SUDO).
request_idUUID gerado no cliente uma vez por intenção do usuário (abrir o diálogo / clicar “Salvar”) e reutilizado em todos os retries da MESMA intenção. Mudar qualquer campo = nova intenção = novo UUID; reaproveitar com payload diferente gera IDEMPOTENCY_KEY_REUSED.
ReplayResposta com replayed: true (estoque, pedidos, despesas) ou created: false (loja, categoria, produto) é sucesso: mostrar o mesmo toast de sucesso e recarregar dados.
Concorrência otimistaexpected_revision obrigatório em contagem de estoque (inventory_balances.revision) e em todas as operações de pedido (orders.revision). STALE_*_REVISION → recarregar, mostrar valores atuais e pedir nova confirmação (com NOVO request_id).
RLS transparenteAs policies filtram por loja; ainda assim, sempre filtre .eq('store_id', storeId) nas listas para usar índices e evitar misturar lojas quando o usuário é SUDO.
UPDATE direto silenciosoUPDATE negado por RLS retorna 0 linhas sem erro. Sempre usar .select() e tratar data.length === 0 como “sem permissão/registro indisponível”.
Numeric/bigintPostgREST e jsonb devolvem numeric e bigint como número JSON. Ver 2.6.
DatasTodas as colunas são timestamptz (ISO). Exibir em America/Sao_Paulo por padrão com Intl.DateTimeFormat('pt-BR', { timeZone }).
PIITelefone/endereço de clientes só em telas autenticadas com customers.read/orders.read. Nunca enviar a analytics, logs ou URLs.

2.4 Wrapper de RPC e parse de erros

tssrc/lib/rpc.ts
// src/lib/rpc.ts
import type { PostgrestError } from '@supabase/supabase-js'
import { supabase } from './supabase'

export class BackendError extends Error {
  constructor(
    public code: string,            // código de negócio (RAISE EXCEPTION) ou SQLSTATE/PGRST
    public sqlState: string,        // ex.: '22023', '42501', '23505'
    public raw?: PostgrestError,
  ) { super(code) }
  get isForbidden() { return this.sqlState === '42501' }
  get isStale() { return this.code === 'STALE_ORDER_REVISION' || this.code === 'STALE_INVENTORY_REVISION' }
  get isNetwork() { return this.code === 'NETWORK_ERROR' }
}

const BUSINESS_CODE = /^[A-Z][A-Z0-9_]{2,80}$/

export function toBackendError(e: PostgrestError | null | undefined): BackendError {
  if (!e) return new BackendError('UNKNOWN', '')
  const msg = (e.message ?? '').trim()
  if (BUSINESS_CODE.test(msg)) return new BackendError(msg, e.code ?? '', e)     // RAISE EXCEPTION 'CODIGO'
  const constraint = /constraint "([^"]+)"/.exec(msg)?.[1]                       // 23505 / 23514 / 23503
  if (constraint) return new BackendError(`${e.code}:${constraint}`, e.code ?? '', e)
  if (e.code === '42501') return new BackendError('FORBIDDEN', '42501', e)       // RLS/GRANT
  if (!e.code && /fetch|network/i.test(msg)) return new BackendError('NETWORK_ERROR', '', e)
  return new BackendError(e.code || 'UNKNOWN', e.code ?? '', e)
}

/** Chamada tipada: rpc<CreateProductArgs, CreateProductResult>('create_product', args) */
export async function rpc<A extends object, R>(fn: string, args?: A): Promise<R> {
  const { data, error } = await supabase.rpc(fn, args as never)
  if (error) throw toBackendError(error)
  return data as R
}

2.5 request_id, client_secret e operações pendentes

// src/lib/ids.ts
export const newRequestId = (): string => crypto.randomUUID()   // v4, minúsculo

/** 32 bytes aleatórios → base64url sem padding = exatamente 43 caracteres */
export function newClientSecret(): string {
  const bytes = crypto.getRandomValues(new Uint8Array(32))
  let bin = ''
  bytes.forEach(b => { bin += String.fromCharCode(b) })
  return btoa(bin).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '')
}

// src/lib/pending.ts — mantém a MESMA chave entre retries (inclusive após recarregar a aba)
interface Pending<T> { requestId: string; fingerprint: string; payload: T; createdAt: number }
export function stablePending<T>(key: string, payload: T): Pending<T> {
  const fingerprint = JSON.stringify(payload)
  const saved = sessionStorage.getItem(key)
  if (saved) {
    const p = JSON.parse(saved) as Pending<T>
    if (p.fingerprint === fingerprint) return p          // mesma intenção → mesma chave
  }
  const fresh = { requestId: crypto.randomUUID(), fingerprint, payload, createdAt: Date.now() }
  sessionStorage.setItem(key, JSON.stringify(fresh))
  return fresh
}
export const clearPending = (key: string) => sessionStorage.removeItem(key)

Uso: const op = stablePending(`order:${orderId}:pay`, form); chamar a RPC com op.requestId; em sucesso (inclusive replay) clearPending; em erro de rede/timeout manter e oferecer “Tentar novamente”; em erro de negócio definitivo (ex.: ORDER_NOT_PENDING) limpar.

export function installGuards(router: Router) {
  router.beforeEach(async (to) => {
    const auth = useAuthStore()
    await auth.ready                                    // getSession() inicial resolvido (seção 6.2)
    const isPublic = to.matched.every(r => r.meta.public)

    if (to.meta.guestOnly && auth.session) return { name: 'app-dashboard' }
    if (isPublic) return true
    if (!auth.session) return { name: 'auth-login', query: { redirect: to.fullPath } }

    const access = useAccessStore()
    await access.ensureLoaded()                         // get_my_access + loja ativa + get_store_access

    if (!access.my?.account_active) { await auth.signOut(); return { name: 'auth-login', query: { reason: 'inactive' } } }
    if (to.matched.some(r => r.meta.sudo)) return access.my.can_manage_security ? true : { name: 'app-dashboard' }

    const needsStore = to.matched.some(r => r.meta.requiresStore)
    const noStoreOnly = to.matched.some(r => r.meta.noStoreOnly)
    if (noStoreOnly && access.storeId) return { name: 'app-dashboard' }
    if (needsStore && !access.storeId) {
      return access.can('store.create') ? { name: 'app-onboarding-plan' } : { name: 'app-profile' }
    }
    const perm = [...to.matched].reverse().find(r => r.meta.perm)?.meta.perm

import { defineStore } from 'pinia'
import { rpc } from '@/lib/rpc'
import { supabase } from '@/lib/supabase'
import type { MyAccess, StoreAccess, PermissionCode } from '@/types/backend'
import type { StoresRow } from '@/types/backend'

export const useAccessStore = defineStore('access', {
  state: () => ({
    my: null as MyAccess | null,
    store: null as StoresRow | null,
    storeAccess: null as StoreAccess,
    loading: null as Promise<void> | null,
  }),
  getters: {
    storeId: (s) => s.store?.id ?? null,
    can: (s) => (p: PermissionCode) => !!s.my?.permissions.includes(p),            // GLOBAL
    hasStore: (s) => (p: PermissionCode) => !!s.storeAccess?.permissions.includes(p), // LOJA
    isSudoPanel: (s) => !!s.my?.can_manage_security,
  },
  actions: {
    ensureLoaded() { return this.loading ??= this.reload() },
    async reload() {
      this.my = await rpc<object, MyAccess>('get_my_access')
      const uid = this.my.user_id
      // Loja própria: no máximo UMA não arquivada (índice stores_one_live_per_owner).
      // Filtrar por owner_id evita listar lojas de terceiros quando o usuário é SUDO (store.admin).
      const { data, error } = await supabase.from('stores')
        .select('*').eq('owner_id', uid!).is('archived_at', null).maybeSingle()
      if (error) throw error
      this.store = data
      this.storeAccess = data ? await rpc<{ p_store_id: string }, StoreAccess>('get_store_access', { p_store_id: data.id }) : null
    },
    reset() { this.$reset() },
  },
})

6.2 Store de autenticação e onAuthStateChange (sem await dentro do callback)

Regra obrigatória

Não chamar await supabase.… (nem RPC, nem getUser) dentro do callback de onAuthStateChange: o SDK mantém um lock interno durante o callback e chamadas aguardadas ali podem causar deadlock. Atualize estado síncrono e agende o trabalho assíncrono com setTimeout(…, 0) (ou queueMicrotask).

tssrc/stores/auth.ts
// src/stores/auth.ts (PROPOSTA)
import { defineStore } from 'pinia'
import type { Session, User } from '@supabase/supabase-js'
import { supabase } from '@/lib/supabase'
import { useAccessStore } from './access'
import { router } from '@/router'

export const useAuthStore = defineStore('auth', {
  state: () => ({ session: null as Session | null, user: null as User | null, ready: null as Promise<void> | null }),
  actions: {
    init() {
      if (this.ready) return this.ready
      this.ready = (async () => {
        const { data } = await supabase.auth.getSession()      // FORA do callback: permitido
        this.session = data.session
        this.user = data.session?.user ?? null
      })()

      supabase.auth.onAuthStateChange((event, session) => {
        // 1) SOMENTE atualização síncrona de estado aqui dentro
        this.session = session
        this.user = session?.user ?? null

        // 2) Trabalho assíncrono agendado para FORA do callback
        setTimeout(() => {
          const access = useAccessStore()
          if (event === 'SIGNED_OUT') {
            access.reset()
            localStorage.removeItem('vibestore:active-store')
            router.replace({ name: 'auth-login' })
          } else if (event === 'SIGNED_IN' || event === 'USER_UPDATED') {
            access.loading = null                              // força novo get_my_access na próxima rota
          } else if (event === 'PASSWORD_RECOVERY') {
            router.replace({ name: 'auth-reset-password' })
          }
        }, 0)
      })
      return this.ready
    },
    async signOut() { await supabase.auth.signOut() },
  },
})

// main.ts: useAuthStore(pinia).init() ANTES de app.use(router) / router.isReady()

6.3 Redirect interno seguro (anti open-redirect)

tssrc/lib/safeRedirect.ts
// src/lib/safeRedirect.ts
const ALLOWED_PREFIXES = ['/app', '/sudo', '/auth/reset-password', '/s/']

/** Aceita SOMENTE caminhos relativos internos. Qualquer outro valor → fallback. */
export function safeRedirect(raw: unknown, fallback = '/app'): string {
  if (typeof raw !== 'string' || raw.length === 0 || raw.length > 512) return fallback
  let value: string
  try { value = decodeURIComponent(raw) } catch { return fallback }
  if (!value.startsWith('/') || value.startsWith('//') || value.startsWith('/\\')) return fallback
  if (/[\u0000-\u001f\\]/.test(value)) return fallback            // controle e barra invertida
  let url: URL
  try { url = new URL(value, window.location.origin) } catch { return fallback }
  if (url.origin !== window.location.origin) return fallback     // ex.: '/\t//evil.com'
  if (url.pathname.startsWith('/auth/callback')) return fallback  // evita loop
  if (!ALLOWED_PREFIXES.some(p => url.pathname === p.replace(/\/$/, '') || url.pathname.startsWith(p))) return fallback
  return url.pathname + url.search                               // descarta hash (nunca propagar #token)
}

// src/lib/media.ts
const EXT: Record<string, string> = { 'image/png': 'png', 'image/jpeg': 'jpg', 'image/webp': 'webp' }
export const LIMITS = { 'store-logos': 2_097_152, 'store-banners': 5_242_880, 'product-images': 5_242_880 } as const
export type Bucket = keyof typeof LIMITS

export function assertImage(file: File, bucket: Bucket) {
  if (!EXT[file.type]) throw new Error('INVALID_IMAGE_TYPE')
  if (file.size > LIMITS[bucket]) throw new Error('IMAGE_TOO_LARGE')
}
export const storeMediaPath = (storeId: string, file: File) => `${storeId}/${crypto.randomUUID()}.${EXT[file.type]}`
export const productMediaPath = (storeId: string, productId: string, file: File) =>
  `${storeId}/${productId}/${crypto.randomUUID()}.${EXT[file.type]}`

/** Banco guarda SÓ o caminho; a URL é montada no cliente (bucket público). */
export const publicUrl = (bucket: Bucket, path: string | null) =>
  path ? supabase.storage.from(bucket).getPublicUrl(path).data.publicUrl : null

// Troca de logo (ordem segura)
export async function replaceStoreMedia(storeId: string, kind: 'logo' | 'banner', file: File, oldPath: string | null) {
  const bucket: Bucket = kind === 'logo' ? 'store-logos' : 'store-banners'
  assertImage(file, bucket)
  const path = storeMediaPath(storeId, file)
  const up = await supabase.storage.from(bucket).upload(path, file, { upsert: false, contentType: file.type })
  if (up.error) throw up.error
  try {
    await updateStore(storeId, kind === 'logo' ? { logo_path: path } : { banner_path: path })
  } catch (e) {
    await supabase.storage.from(bucket).remove([path])       // limpa órfão
    throw e
  }
  if (oldPath) await supabase.storage.from(bucket).remove([oldPath])   // best-effort
  return path
}

const key = (orderId: string, op: Op) => `order:${orderId}:${op}`

async function run<A extends object>(orderId: string, op: Op, fn: string, args: Omit<A, 'p_request_id'>) {
  const pending = stablePending(key(orderId, op), args)
  try {
    const r = await rpc<A, OrderOperationResult>(fn, { ...args, p_request_id: pending.requestId } as A)
    clearPending(key(orderId, op))
    return r                                   // r.replayed=true também é sucesso
  } catch (e) {
    if (e instanceof BackendError && !e.isNetwork) clearPending(key(orderId, op))
    throw e
  }
}

// src/services/storefront.service.ts (PROPOSTA)
const URL_ = (import.meta.env.VITE_STOREFRONT_API_URL as string)
  || `${import.meta.env.VITE_SUPABASE_URL}/functions/v1/storefront-api`
const ANON = import.meta.env.VITE_SUPABASE_ANON_KEY as string

export class StorefrontError extends Error {
  constructor(public status: number, public code: StorefrontErrorCode | 'NETWORK_ERROR', public retryAfter?: number) { super(code) }
  get retryable() { return this.status === 0 || this.status === 429 || this.status === 503 }
}

async function call<T>(body: object, signal?: AbortSignal): Promise<T> {
  let res: Response
  try {
    res = await fetch(URL_, {
      method: 'POST',
      headers: { 'content-type': 'application/json', apikey: ANON },   // sem Authorization do usuário
      body: JSON.stringify(body),
      signal,
    })
  } catch { throw new StorefrontError(0, 'NETWORK_ERROR') }
  const json = await res.json().catch(() => ({ error: 'SERVICE_UNAVAILABLE' }))
  if (!res.ok || 'error' in json) {
    throw new StorefrontError(res.status, json.error ?? 'SERVICE_UNAVAILABLE', Number(res.headers.get('retry-after')) || undefined)
  }
  return json.data as T
}

export const storefrontApi = {
  catalog: (store_slug: string, filters: CatalogFilters = {}, signal?: AbortSignal) =>
    call<CatalogData>({ action: 'catalog', store_slug, filters }, signal),
  product: (store_slug: string, product_slug: string) =>
    call<ProductData>({ action: 'product', store_slug, product_slug }),
  checkout: (req: Omit<CheckoutRequest, 'action'>) =>
    call<CheckoutData>({ action: 'checkout', ...req }),
  orderStatus: (store_slug: string, order_id: string, token: string) =>
    call<OrderStatusData>({ action: 'order-status', store_slug, order_id, token }),

textFluxo 3

23.4 Reserva expirada

  • Após 24 h a reserva deixa de contar (expires_at); o pedido segue PENDING e visível ao lojista com badge “Reserva expirada”.
  • O cliente ainda vê o pedido; reservation_active=false na página de acompanhamento (texto: “a disponibilidade será confirmada pela loja”).
  • Pagamento ainda é possível se houver estoque disponível; caso contrário INSUFFICIENT_AVAILABLE_STOCK_FOR_PAYMENT → registrar entrada ou cancelar.
